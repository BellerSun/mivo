# 使用与排障

[返回首页](../README.md)

## 连接与首次使用

通过 USB 连接 DJI Mic Mini 2 接收器，操作发射器侧面的配对键。在 Mivo 与目标应用中设置相同的快捷键和触发方式，再通过 Mivo 设置开启辅助功能与输入监控。

按住模式下，短按一次持续按住目标键，再按一次松开；松开后 3 秒内再按可发送回车，该选项可关闭。点按模式下，每次短按发送一次完整按键，不判断目标应用的开始或结束，也不进入发送窗口。模式和按键立即生效并保存，切换时先释放旧按键。

模拟按键预设左／右 Command 和 Fn（实验），自定义入口支持输入键名或从键盘录入单键、修饰键组合。Fn 可生成模拟事件，但是否触发系统或目标应用动作需实际验证。

## 面板与悬浮提示

- 点击菜单栏图标打开状态面板，查看设备状态或暂停控制。暂停会保存，重连和重启不会自动取消暂停。
- 悬浮提示显示下一次按键动作：蓝色按住／点按、橙色松开、绿色发送；不可用时显示灰色原因。悬浮窗可整块拖动并记住位置，不抢输入焦点。
- 默认迷你样式为 44 × 44 图标方块，沿圆角边框显示发送倒计时。设置中可切换标准样式或隐藏提示，立即生效并保存；隐藏提示不会暂停控制。
- 悬浮窗右键菜单提供「打开主窗口」和「退出」。菜单栏图标被刘海遮挡时，可从设置底部的「显示面板」打开状态面板。
- 设备示意中的高亮键用于指引操作。正常模式点击示意只打开说明；开发模式点击才会模拟按键。

## 权限不生效

设置中的「设备与权限」显示当前进程的真实 API 检测结果，每 2 秒刷新。标题旁的问号提供应用路径、重新检测、在访达中显示和重启。

如果系统开关与检测结果不一致，先重启 Mivo；仍不一致时，在系统设置移除旧 Mivo，再添加 `/Applications/Mivo.app`。也可从问号弹层主动选择「修复辅助功能授权」，确认后仅重置 Mivo 的辅助功能授权，再由你手动重新授权；不影响其他应用和输入监控。

不要修改 TCC 数据库或关闭系统保护。更新应沿用原签名身份，详见[开发与签名](development.md)。

## 兼容性与已知限制

- 当前识别的接收器 USB Vendor ID / Product ID 为 `0x2CA3 / 0x4011`，操作对象为 DJI Mic Mini 2 发射器的配对键。其他型号、固件和连接方式尚未建立验证矩阵。
- 目标应用需支持所选快捷键及按住／点按触发方式；目前没有完整应用版本兼容矩阵，升级后需实际验证。
- Mivo 不检查当前前台应用。模拟快捷键和「结束后再按发送」的回车会作用于当前输入环境，回车可能提交当前应用中的内容；使用前确认输入焦点，或在已有设置中关闭再按发送。
- 控制期间仅修改匹配接收器服务的音量增减键映射，保留其他映射；正常暂停、退出或启动失败时尝试恢复每个服务的原映射。若检测到其他工具已修改映射，保留外部设置，不用旧快照覆盖。
- 映射快照只在当前进程内保存。强制结束或崩溃无法保证执行恢复；拔插接收器后再检查映射。设备移除后不把旧快照写入新连接的服务。恢复失败会记入诊断日志。

## 隐私与权限

Mivo 自身不采集或保存音频、不执行语音识别，没有网络上传或遥测逻辑。语音由你选择的目标应用处理，其数据行为需以该应用的说明为准。

辅助功能和输入监控用于读取目标设备事件、拦截接收器映射的传输按键（F20）及发送所选模拟按键；Mivo 不记录输入正文或剪贴板。偏好设置仅在本机保存控制开关、模拟方式与快捷键、发送选项、悬浮样式及位置。诊断日志最多保留 500 条于进程内存，包含控制动作、时间、权限状态和错误；诊断窗口还显示电脑名称与系统版本，权限帮助显示应用路径。提交日志或截图前请遮盖姓名、电脑名、路径及其他个人信息。

签名私钥仅保存在本机钥匙串。不要提交签名配置、私钥、证书导出包或完整本机诊断文件。安全问题的反馈方式见 [安全反馈](../SECURITY.md)。

## 卸载与反馈

先从 Mivo 菜单退出，使应用有机会恢复设备映射，再删除 `/Applications/Mivo.app`。需要清理系统授权时，可在系统设置的辅助功能与输入监控中手动移除 Mivo。卸载不会自动删除偏好设置或签名身份；计划重新安装或更新时应保留原身份，不要为排障重建同名证书。

普通问题可提交 GitHub Issue，附上 Mivo 版本、macOS 版本、CPU 架构、设备型号及固件、目标应用及版本、复现步骤、预期和实际行为，并注明真实设备或开发模式。不要公开密钥或未脱敏诊断信息。贡献流程见 [贡献指南](../CONTRIBUTING.md)。
